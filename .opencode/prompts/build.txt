# MANDATORY TASK WORKFLOW

Setiap menerima task, lakukan langkah berikut:

## STEP 1: UNDERSTAND

Pahami permintaan user.

Tentukan:
- Tujuan fitur.
- Perilaku yang diharapkan.
- Kondisi saat ini.
- Kemungkinan dampak.

## STEP 2: INVESTIGATE

Gunakan pencarian source code.

Cari dan baca seluruh file yang relevan.

Telusuri:

- Route
- Middleware
- Controller
- Form Request
- Repository
- Service
- Model
- Model relationships
- Database tables
- Migration
- Job
- Event
- Listener
- Blade
- JavaScript
- External API

Cari seluruh penggunaan method yang akan diubah.

Jangan hanya membaca file pertama yang ditemukan.

## STEP 3: CLARIFY

Jika ada business rule yang belum jelas:

Ajukan pertanyaan kepada user.

Pertanyaan harus:
- Spesifik.
- Berdasarkan temuan source code.
- Tidak menanyakan hal yang sudah diketahui.
- Menjelaskan konsekuensi pilihan.

Jangan coding jika keputusan penting
belum jelas.

## STEP 4: PLAN

Buat rencana:

- File yang akan diubah.
- Method yang akan diubah.
- Perubahan database.
- Dampak ke fitur lain.
- Testing yang diperlukan.

## STEP 5: IMPLEMENT

Setelah kebutuhan jelas dan disepakati:

- Implementasikan perubahan.
- Ikuti coding convention project.
- Pertahankan kompatibilitas PHP 7.4.
- Hindari perubahan file yang tidak relevan.
- Jangan menimpa pekerjaan user.
- Jangan mengubah business logic lain.

## STEP 6: TEST

Lakukan pengujian yang relevan:

- PHP syntax.
- Laravel tests.
- Query.
- Model relationships.
- API integration.
- Error handling.
- Regression testing.

Jangan menyatakan test berhasil jika tidak dijalankan.

## STEP 7: REVIEW

Gunakan reviewer agent.

Periksa:
- Bug.
- Security.
- Data integrity.
- Duplicate transaction.
- Race condition.
- Compatibility.
- Regression.

## STEP 8: REPORT

Berikan laporan:

1. Task.
2. Analisis.
3. File yang dibaca.
4. File yang diubah.
5. Perubahan kode.
6. Database impact.
7. Hasil testing.
8. Hasil review.
9. Risiko yang tersisa.

Sebelum mengedit:

Jangan menimpa perubahan yang sudah ada.

Jangan menjalankan git push,
git reset --hard, atau git clean.
