# CRUD ProductUom

Konvensi: Laravel 8, PHP 7.4. Model baru → Repo extends `BaseRepository`
(lokasi repo: `App\Http\Repository\MasterData\Toko\{Name}Repo`, mengikuti
namespace `UnitRepo`). Controller pakai trait `ApiResponse`.
Helper global di `GlobalService`.

## Lokasi
- Model: `App\Models\MasterData\Toko\ProductUom`
- Controller CRUD: `App\Http\Controllers\Toko\MasterData\ProductUomController`
- Repo: buat `ProductUomRepo` (extends BaseRepository) jika belum ada
- Pola referensi: `UnitController` (getAll, getById, store — store menangani
  create & update via `id` nullable; tidak ada delete)

## Relasi & skema `product_uoms`

## Route, harus ada route name dan tidak boleh sama
- `routes/api.php`:
  - Store: `save-item-productuom`
  - Index: `getAllPaginateUom` camelCase
  - getById: ⚠️ `detailItemUom`
  - Dropdown produk (function baru di ProductUomController): ⚠️ nama belum ditentukan
  - Dropdown unit: reuse `UnitController::getAll`
- `routes/web.php`:
  - View halaman: ⚠️product-uom-web

## Menu
Tambah ke `MasterMenuSeeder`, ikuti pola:
```php
$child_menus = [..., 'product-uom'];   // ⚠️ atau 'product-uom'? cek konsistensi hyphen
$slug_web = [..., 'toko/admin/master-data/product-uom'];
```
Ditambahkan di posisi index yang sama pada kedua array, lanjut dari entri
`unit` yang sudah ada.
